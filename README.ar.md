# Hoodmin

[Türkçe](README.md) · [English](README.en.md) · [العربية](README.ar.md)

Hoodmin لوحة إدارة مستقلة لبيئات VpnHood، مكتوبة بلغة Rust. تدير كل مؤسسة خوادم VPN الخاصة بها ومفاتيح الوصول والجلسات والشهادات في مساحة عمل منفصلة. ترسل التطبيقات العميلة حركة VPN مباشرة إلى خوادم VpnHood.

- تثبيت خادم VpnHood على Linux، ودعم SSH، وملفات تعريف الخوادم، والتوجيه داخل المجموعات.
- إنشاء مفاتيح الوصول دفعة واحدة، وملفات تعريف الوصول، وحدود السرعة والأجهزة وحركة البيانات والمدة.
- شهادات PFX، وإصدار تلقائي عبر Let's Encrypt باستخدام HTTP-01، ونشر عناوين مشفّرة.
- تقارير الاستخدام، وسجل التدقيق، وأدوار الفريق، وحسابات آلية، وواجهة JSON API.
- واجهة بالتركية والإنجليزية والعربية مع سمتين فاتحة وداكنة.
- PostgreSQL محلي أو بعيد، وترقيات Debian تلقائية، ونسخ احتياطية مشفّرة، وتدوير المفاتيح، وإشعارات.

بيئة التحقق المرجعية هي Debian 13 amd64 وVpnHood 9.0.856. تعمل اللوحة مع خادم VpnHood الرسمي وتطبيقاته العميلة.
