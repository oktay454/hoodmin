# Hoodmin

[Türkçe](README.md) · [العربية](README.ar.md) · [English](README.en.md)

Hoodmin **لوحة مستقلة لإدارة VPN، متوافقة مع VpnHood** ومكتوبة بلغة Rust. تدير خوادم VPN ومفاتيح الوصول والاتصالات وحصص حركة البيانات والشهادات. ليست منتج VpnHood Manager الرسمي؛ تستخدم الخوادم والعملاء برمجيات VpnHood الرسمية.

تجلب كل مؤسسة خوادم VPN الخاصة بها (BYOS). ينتمي الخادم إلى مستأجر واحد (tenant). يتصل العميل بخادم VPN مباشرة؛ لا تمر حركة VPN عبر اللوحة.

## التثبيت على Debian 13 amd64

1. وجّه اسم نطاق اللوحة، مثل `hoodmin.example.com`، إلى مضيفها وافتح TCP 80/443. يمكن تشغيل اللوحة وخادم VPN على جهازين وباسمَي نطاق منفصلين.
2. نفّذ بصلاحيات root من مجلد الحزمة:

```bash
apt install ./hoodmin_0.1.0-7~deb13u1_amd64.deb
systemctl enable --now postgresql
hoodmin-db-setup
hoodmin-create-owner vpn@example.com https://hoodmin.example.com
```

3. اضبط Nginx وشهادة HTTPS موثوقة باتباع [دليل التثبيت التفصيلي](docs/uretim-kurulumu.md). الدليل التفصيلي ودليل الاستخدام باللغة التركية. يجب أن تطابق `VHM_PUBLIC_ORIGIN` عنوان HTTPS العام تمامًا، دون شرطة مائلة نهائية. يوجّه Nginx الطلبات إلى `127.0.0.1:3080` ويستبدل رؤوس عنوان العميل بالقيمة الفعلية.
4. بعد إعداد HTTPS شغّل اللوحة:

```bash
systemctl enable --now hoodmin.service
curl --fail --show-error https://hoodmin.example.com/healthz
```

5. اقرأ `/root/hoodmin-first-owner.json` على جهاز التثبيت من جلسة root موثوقة. يحتوي البريد وكلمة المرور العشوائية الأولى. سجّل الدخول وغيّر كلمة المرور من **حسابي**. لا توجد كلمة مرور افتراضية أو صفحة تسجيل عام.
6. من **الخوادم** سجّل عنوان IP أو FQDN العام لخادم VPN ومنفذ TCP. نفّذ أمر التثبيت الرسمي الذي تولّده اللوحة على خادم VPN، أو استخدم نموذج SSH مع التحقق من بصمة المضيف. انتظر ظهور الخادم متصلاً.
7. من **مفاتيح الوصول** أنشئ مفتاحًا واستورد قيمة `vh://` في عميل VpnHood الرسمي. حساب اللوحة ومفتاح VPN بيانات اعتماد مختلفة.

تثبّت الحزمة اللوحة ولا تتضمن خادم VPN. لا تشغّل نصوص إعداد بيئة الاختبار المعزولة على تثبيت قائم.

## الميزات

- التركية والعربية والإنجليزية، واتجاه RTL للعربية، ومظهر فاتح وداكن، ومساعدة سياقية.
- أوامر التثبيت الرسمي على Linux، والتثبيت وإعادة التثبيت عبر SSH، وأوامر PowerShell لـ Windows.
- إعدادات خوادم VPN وقوالب قابلة لإعادة الاستخدام وتطبيق تلقائي على المجموعات المرتبطة.
- مفاتيح وصول جماعية وملفات وصول وحدود السرعة والأجهزة والبيانات والمدة وإنهاء جلسات VPN.
- توجيه داخل مجموعة المستأجر وتجديد العناوين المشفرة ونشرها إلى تخزين HTTPS خارجي.
- استيراد PFX وشهادات مشتركة للمجموعة وAutoSign لكل خادم باستخدام Let's Encrypt HTTP-01.
- رسوم الاستخدام وعدد الأجهزة حسب البلد المبلّغ عنه وتصدير CSV وسجل تدقيق.
- خمسة أدوار للفريق ومفاتيح بوت محددة المدة وواجهة JSON للإدارة.
- PostgreSQL RLS وكلمات مرور Argon2id وحماية أسرار الإدارة المخزنة بـ AES-256-GCM.

## التشغيل والمراجع

- [دليل Hoodmin](docs/elkitabi.md): القوائم والخادم الأول والمفاتيح والملفات والصلاحيات.
- [AutoSign](docs/autosign.md): يجب أن يصل DNS وTCP 80 الخارجي إلى خادم VPN. ابدأ بهيئة الاختبار؛ لا تُطبّق شهادتها على VPN. يطبّق الوضع الحقيقي PFX بعد التحقق ويفحص التجديد كل 12 ساعة. لا تستخدم مؤقّت Certbot آخر لإدارة الشهادة نفسها.
- [النسخ الاحتياطي والاستعادة](docs/yedekleme.md): نفّذ `hoodmin-backup` بصلاحيات root. احفظ نسخة قاعدة البيانات و`/var/lib/hoodmin/master.key` والإعدادات وشجرة `acme` معًا. انقل نسخة مشفرة إلى جهاز مستقل. يحتاج `hoodmin-backup-export` إلى حزمة `age` الاختيارية ومفتاح استعادة محفوظ بشكل مستقل. لا تُحذف النسخ القديمة تلقائيًا.
- [استكشاف الأخطاء](docs/sorun-giderme.md): استخدم `systemctl status hoodmin` و`journalctl -u hoodmin`.
- [المعمارية](docs/mimari.md)، [API](docs/yonetim-api.md)، [البروتوكول](docs/protokol-uyumlulugu.md)، [البناء والتحقق](docs/dogrulama.md).

البرنامج `/usr/bin/hoodmin`، والخدمة `hoodmin.service`، والإعدادات `/etc/hoodmin/hoodmin.env`، والبيانات `/var/lib/hoodmin`. أسماء حساب الخدمة ودور PostgreSQL `vhmgr` وقاعدة البيانات `vpnhood_manager` وإعدادات `VHM_*` وملفات الارتباط `__Host-vhm_*` أسماء تقنية ثابتة. يعتمد عليها التحقق المحلي (peer authentication) وملكية البيانات؛ تغيير اسم المنتج لا يغيّر أسماء هذه الموارد.

قبل الترقية خذ نسخة احتياطية وأوقف الخدمة، ثم ثبّت الحزمة الجديدة ونفّذ `hoodmin-db-setup` وأعد تشغيل الخدمة. احتفظ بالمفتاح الرئيسي وملف البيئة. تحقّق من الاستعادة في قاعدة منفصلة قبل استبدال تثبيت قائم.

## نطاق الدعم

هدف التوافق VpnHood **9.0.856** على Debian 13 amd64. لم يُختبر تثبيت Windows من البداية إلى النهاية. يدعم AutoSign اسم FQDN واحدًا لكل خادم وHTTP-01؛ لا يدعم نطاقات wildcard أو DNS-01 أو إصدارًا جماعيًا للمجموعة. لا تتوفر محركات VPN أخرى أو طلب عناوين سحابية أو فواتير أو علامة مخصصة للمستأجر أو تسجيل عام. لا تتوفر آلية تدوير المفتاح الرئيسي أو تنبيهات خارجية أو حذف تلقائي للنسخ. لم تكتمل اختبارات الحمل والانقطاع الطويل أو جميع مسارات سطح المكتب؛ لا ندعي التكافؤ الكامل مع Manager التجاري.
