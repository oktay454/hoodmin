# paste uyumluluk yönlendirmesi

Leptos 0.8 bileşenleri paste makrosunu kullanır. Orijinal paste paketi bakım dışı kaldığından (RUSTSEC-2024-0436), bu küçük yerel kitaplık aynı makro yolunu bakımı süren pastey 0.2.3 paketine yönlendirir. Orijinal paste kaynak kodunu içermez ve uyarı bastırması kullanmaz. Makro uygulaması Cargo.lock içindeki crates.io doğrulama toplamıyla sabittir.

Bu geçici uyumluluk katmanı, Leptos'un bağımlılığını kendisi güncellemesinden sonra kaldırılabilir.
